Locked · Live · Reveal States
Mockup set 2 — App State Machine
Three app states based on GW phase. Locked/Live replaces the Build View while matches are playing — the Moments View anchors the experience chronologically with the BoldnessHeroCard at top. Reveal is one-time, auto-triggered on first open after GW ends. No button press needed.
App State Machine — 3 GW States
Building
Odds locked → first kick-off.
Fixture accordion, 0–20 counter, Save CTA.
→
First kick-off
Locked / Live
Kick-off → last final whistle.
Moments View + hero card. All picks pending.
→
GW ends · first open
Reveal
Auto on first open. One-time.
Sequential animation → share → done.
→
Viewed / shared
Building
Next GW. Fresh slate.
Reveal never replays for prior GW.
